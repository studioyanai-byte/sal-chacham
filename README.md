# סל חכם – השוואת מחירים בסופר (שירות לציבור, גרסת הרצה)

- `index.html` – האפליקציה (עברית / רוסית / אמהרית, נגישות לפי ת"י 5568 AA).
- `data.json` – מחירים אמיתיים מקבצי השקיפות של הרשתות (חוק המזון).
- `.github/workflows/update-prices.yml` – עדכון אוטומטי של המחירים כל שעה.
- `scripts/` – הורדת קבצי המחירים ועיבודם.

המחיר המחייב הוא המחיר בקופה.
